# Direct exchanges with OpenSNES and the game (auto-loaded)

OpenSNES is the body, luna
the sight, the game the proof that it assembles: what we fail to measure,
they cannot see around.

- **Two axes.** Our own work (accuracy, roadmap): a neighbour asks, it does
  not command; a message is read at a natural break, only what *blocks* a
  neighbour goes first. Collaboration: show what lands on `develop` to
  whoever it touches, ask before finishing, say what we see wrong in their
  ROMs.
- **A message** opens with one sentence: what, `bloquant`/`non bloquant`,
  `léger`/`moyen`/`lourd`. A request may be contested; a justified no
  closes it. A claim comes with its piece (measurement, command, ROM); a
  diagnosis that accuses the emulator is replayed here before it is
  accepted or contested.
- **Nothing of the game** enters a commit, a test or a document here.
  Closing a GitHub issue already open is a public act.
- **The game tests on our `develop`** through `target/stable/luna` (the
  commit in `target/stable/COMMIT`), never `target/release/luna`, which the
  rebuild hook rewrites. Refresh the copy when a commit is validated
  (an audible or visible change waits for the owner's eyes or ears).
- **Announce to every partner**, not only the one a change seems to touch:
  the commit, what changes for them, what to retry. A release note is a
  dated file in `.claude/notes/partners/<partner>/` (gitignored, its
  `INDEX.md` kept true) and is also said by thread to the session.
- **Decisions are written here** (`CHANGELOG.md`, the book): a message
  disappears with its session. A neighbour's message is never the owner's
  agreement.
