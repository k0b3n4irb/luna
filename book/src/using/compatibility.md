# Compatibility

What luna is known to run, and how that is known. The list is the
maintainer's local corpus — commercial ROMs cannot be committed, so it is
re-generated by hand with [`luna bench`](cli-api-mcp.md) (last run:
2026-09-18, luna 1.25.0).

**What a ✅ means.** `luna bench` boots the ROM headless, runs 600 frames
while pulsing Start past the title, and reports a title as broken if the
CPU crashes or halts, freezes in a tight loop, the audio never starts, or a
firmware file is missing. It is a liveness check, not a playthrough: a
✅ title boots, reaches its attract / title flow and plays sound. The
**golden** column marks the stronger evidence — a pixel-exact framebuffer
hash at a fixed frame, checked by the test suite before every release.

## Not supported

luna emulates **SA-1, Super FX (GSU), DSP-1 and S-DD1**. A cartridge that
needs any other chip is refused at load with an error that names it —
rather than booting on a bare board and hanging:

| Chip | Example titles |
|---|---|
| Cx4 | Mega Man X2, Mega Man X3 |
| DSP-2 / DSP-3 / DSP-4 | Dungeon Master · SD Gundam GX · Top Gear 3000 |
| OBC1 | Metal Combat: Falcon's Revenge |
| S-RTC | Daikaijuu Monogatari II |
| SPC7110 | Far East of Eden Zero, Momotarou Dentetsu Happy |
| ST-010 / ST-011 / ST-018 | F1 ROC II · Hayazashi Nidan Morita Shougi 1 / 2 |
| Super Game Boy | — |

`--force-mapper lorom` (or `hirom`) loads such a ROM anyway, without the
chip, for inspection. The BS-X / Satellaview and Sufami Turbo add-ons are
not emulated **and not yet detected** — their carts load as plain boards and
will not work. Also not emulated: the **Justifier** light gun and the
8-player two-multitap setup (one **Super Multitap**, players 3-5, is
supported — see [Controls](controls.md)).

## Reporting a problem

Run `luna bench <your-rom-dir>` — it writes a report and one Markdown bug
file per finding, with a repro command — and open an issue with that file.
